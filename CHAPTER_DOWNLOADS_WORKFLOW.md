# Chapter Downloads Workflow Guide

## How to Link Downloads to Chapters

### Important: Downloads are NOT linked in the Chapter Form
The chapter form is for creating/editing chapter details (title, description, YouTube video URL, position). Downloads are linked **separately** after the chapter is created.

### Step-by-Step Process:

#### 1. Create a Chapter
- Click "Add Chapter" button next to a module
- Fill in:
  - Chapter Title (required)
  - Chapter Description (optional)
  - YouTube Video URL or ID (required for new chapters)
  - Position (Sort Order) - lower numbers appear first
- Click "Add Chapter"

#### 2. Link Downloads (Automatic)
- **After creating a chapter**, a "Link Downloads to Chapter" modal will **automatically open**
- This modal shows:
  - **Linked Downloads** section: Downloads already linked to this chapter
  - **Available Downloads** section: All downloads you can link
- To link a download:
  - Find it in the "Available Downloads" list
  - Click the "Link" button next to it
- To unlink a download:
  - Find it in the "Linked Downloads" section
  - Click the "Unlink" button

#### 3. Link Downloads Later (Manual)
If you closed the modal or want to add more downloads later:
- Find the chapter in the module list
- Click the **"📎 Downloads (X)"** button next to the chapter
- The same modal will open where you can link/unlink downloads

## Editing Chapters and Modules

### Edit a Module:
- Find the module in the course editor
- Click the **"✏️ Edit"** button next to the module
- Update title, description, or position
- Click "Update Module"

### Edit a Chapter:
- Find the chapter in the module list
- Click the **"✏️ Edit"** button next to the chapter
- Update title, description, video URL, or position
- Click "Update Chapter"

## Visual Indicators

- **Position numbers** are displayed next to modules and chapters (e.g., "Pos: 0")
- **Download count** is shown on the Downloads button (e.g., "Downloads (3)")
- **"No downloads linked yet"** message appears if a chapter has no downloads
- **"X download(s) linked"** message appears if downloads are linked

## Troubleshooting

### If you don't see Edit/Downloads buttons:
1. **Hard refresh your browser**: Press `Ctrl + Shift + R` (Windows) or `Cmd + Shift + R` (Mac)
2. Clear browser cache (see `CACHE_CLEAR_GUIDE.md`)
3. Check that you're viewing an existing chapter (not the creation form)

### If downloads modal doesn't open automatically:
- This might happen if there's a network delay
- Simply click the "Downloads" button next to the chapter manually

### If you can't find downloads to link:
- Make sure you've created downloads first in the Admin panel → Downloads section
- Only downloads created in the Downloads admin section can be linked to chapters
